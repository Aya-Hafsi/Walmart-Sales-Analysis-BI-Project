# 🛒 Walmart Sales Analysis - BI Project
This Business Intelligence project analyzes Walmart's sales data through a complete BI pipeline - from data extraction to interactive visualization.

## 🎯 Project Goals
- Identify top-performing stores and product categories
- Analyze customer purchasing patterns
- Build a scalable data warehouse solution
- Create actionable insights through dashboards

## 📌 Overview  
A comprehensive BI project analyzing Walmart sales data using:
- **ETL Pipeline**: Azure Blob Storage, Python (Pandas)  
- **Data Warehouse**: Snowflake  
- **Data Modeling**: Star Schema  
- **Visualization**: Power BI  

## 🛠️ Technologies Used  
| Category        | Technologies/Tools |
|----------------|-------------------|
| **ETL**        | Python, Pandas, Azure Blob Storage |
| **Warehouse**  | Snowflake |
| **Modeling**   | Star Schema, Dimensional Modeling |
| **Visualization** | Power BI |
| **Data Sources** | CSV, Excel, JSON, Kaggle/HuggingFace APIs |


## 🔍 Key Insights  
1. **🏪 Store Performance**: 
   - California, Texas, and Florida generated 4.4% of total sales each
   - Opportunity to boost sales in lower-performing states (2.47% average)

2. **📦 Product Trends**: 
   - Keytronic keyboards dominated sales
   - "Tea Powder" showed highest profit margins

3. **👥 Customer Segmentation**: 
   - Corporate clients = 44.76% of orders
   - 20-30 age group showed highest purchasing frequency
